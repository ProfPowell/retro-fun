// CODE REVIEW SIMULATOR //

PR REVIEW STORM

Each level introduces a new kind of PR offender. They start showing up together later.

Move left/right to catch incoming PRs. Your tray holds 3.

The bottom of the tray auto-reviews over ~1.5s.

Tap BOUNCE to send the bottom PR back before it merges — but it returns angrier and redder.

Auto-merging garbage hurts. Letting it hit main hurts more.

⌨ arrows or A/D to move · SPACE / F to bounce
